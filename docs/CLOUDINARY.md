# Cloudinary

Isi cloud name, API key, dan API secret. Browser meminta signature dari `/api/cloudinary/sign`; endpoint memverifikasi sesi, role, purpose, MIME, dan batas 8 MB. Folder dibatasi di bawah `manzsa-residence/`.

Gunakan authenticated delivery untuk bukti pembayaran atau dokumen sensitif. Jangan buat unsigned preset publik dan jangan masukkan identitas ke public ID.
