# Manzsa Residence

Foundation aplikasi pengelolaan satu kos berbasis Expo, React Native, TypeScript, Expo Router, dan React Native Web.

## Menjalankan project

```powershell
npm.cmd install
npm.cmd run web
npm.cmd run android
```

Gunakan `.env.example` sebagai daftar konfigurasi client Firebase. Nilainya belum dibutuhkan hingga Milestone 2.

## Validasi

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run export:web
```

Dokumen PRD, `DESIGN.md`, dan `index.html` adalah referensi dan tidak boleh diubah tanpa permintaan eksplisit.
